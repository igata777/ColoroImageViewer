# 取扱説明書用画像

このフォルダには、`docs/取扱説明書.md` から参照する画像を置きます。

現在は仕様変更に追従しやすい模式図を中心にしています。実画面スクリーンショットを追加する場合は、本文側の画像参照を差し替えるか、同じ説明箇所の近くに追記してください。

推奨する命名:

- `main-form-*.png`: メインフォームや読み込み操作
- `image-view-*.png`: 画像情報画面
- `profile-line-*.png`: Line プロファイル
- `profile-box-*.png`: Box プロファイル
- `profile-measure-*.png`: 2 点測定や統計表示
- `large-image-*.png`: 巨大画像表示
